# gridmind — play, solve, learn

Live app: **https://sks-balan.github.io/gridmind/**

Gridmind is an offline-capable Sudoku app and an interactive introduction to
constraint solving and machine learning. Everything runs locally in the
browser: the puzzle, progress, and lesson state are not uploaded to a server.

## What is included

- A responsive Sudoku game with pencil notes, undo/redo, teaching hints,
  conflict feedback, puzzle persistence, and solver visualisation.
- A browser-native machine-learning curriculum with interactive exercises,
  theory, progress stored on the device, and links to relevant source code.
- Reader-facing design documentation and a curated, read-only source browser.
- An installable Progressive Web App. On iPhone or iPad, open the site in
  Safari and choose **Share → Add to Home Screen**. Other supported browsers
  provide an **Install app** action.

After one complete online load, the app and bundled learning material work
offline. This public repository contains the generated static site; development
happens in the private `gridmind-labs` source repository.
